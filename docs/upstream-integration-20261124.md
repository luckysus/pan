# 1641 / 1037 更新说明

本轮采用逐项适配，保留现有 PHP/Mustache、28 套主题、页面布局、会员、空间包和流量计费。没有整体合并上游 Nuxt 前后台。

## 1. 下载和存储修复

- 单字节、后缀、开放尾部 Range 正确处理；有效但超出文件范围返回 416；If-Range 不匹配回完整内容。
- 不存在或被封禁的下载返回真实 HTTP 404；预览原有占位图设计保持。
- 自定义本地目录补齐路径分隔符；修正本地和七牛的 MIME 元信息。

## 2. Markdown 和代码预览

文件详情中的「查看内容」进入高级预览，支持 Markdown 阅读/源码切换、代码高亮、行号和换行开关。`text.php` 及原始文本外链继续提供原始文本。

预览沿用文件密码、审核、文件大小和分享流量限制；Markdown 不执行 HTML/脚本，不加载文件内容中的远程图片。依赖为本地固定版本，许可证与来源见 `assets/vendor/text-preview/`。可以在页面布局编辑器调整新预览页卡片。

## 3. 批量文件操作

账户及游客「我的文件」均有批量复制外链和批量改名。改名支持查找替换、前缀、后缀和保留扩展名，先显示预览，再确认执行。重复名称、无权限、文件已变化等逐项跳过并反馈；预览不修改数据。列表局部刷新。

## 4. 多存储实例

入口：后台「存储类型设置 → 管理多存储实例」。

1. 选择存储类型并填写独立桶、账号或目录。密钥编辑时不回填，留空保留原值。
2. 配置上传权限，保存后使用连接测试。开启原有「同时开放多个存储」后，可用实例会出现在上传下拉框。
3. 可将启用且面向所有人的实例设为默认。停止新上传不会删除实例配置，也不中断已经获准的上传或历史链接。

旧文件的非空 `storage` 继续使用原类型引用。新文件保存 `inst_实例编号`；升级时仅将历史空引用按当时原默认存储固定一次，避免以后切默认时误读新桶。状态、刷新令牌和扩展驱动远端 ID 映射相互隔离。

实例开始真实上传后连接参数冻结，需要换桶/路径时新建实例；改名、上传权限和启停仍可调整。连接测试及普通页面访问不会冻结尚未使用的实例。

本地实例必须使用已存在的独立绝对目录。目录失效时会报错，不能回退到默认目录。系统拒绝可识别的重复目标；不要以不同域名、凭据或协议入口重复配置同一实际对象目录，远端别名无法仅凭表单完全识别。

API 上传新增可选 POST 字段 `storage`，例如 `inst_12`，使用与网页相同的可用列表/会员门槛；不填时使用默认。仅在所选实例已有相同内容时秒传；编辑始终保存到原实例。相同 hash 的不同未完成上传任务会被拒绝，避免覆盖会话；同一任务可重试。

## 5. 依赖与部署

PHP 最低版本保持 7.4。新 `includes/composer.lock` 固定必要的 HTTP 依赖与兼容桥，不整体替换其他手工 SDK。具体版本、官方公告、CA 配置和验证范围见 [SDK 兼容说明](storage-sdk-compatibility.md)。

升级步骤：

1. 备份站点文件及数据库。
2. 更新源码、`assets/vendor/text-preview/` 及 `includes/lib/HttpCompat.php`。
3. 在 `includes/` 运行 `composer install --no-dev --optimize-autoloader`，或完整上传本轮对应的 `includes/vendor/`。在线更新原本不覆盖 vendor，不能只点在线更新就认为依赖已升级。
4. 访问 `/install/update.php`，验证管理员身份完成 1037 迁移。重复执行可以补齐缺失结构，不清空原数据。
5. 核对原存储、旧链接、新实例、预览、会员及计费。自建 HTTPS 服务应配置可信 CA，不能通过关闭 TLS 校验兼容。

Git 源码交付包含本轮 9 个回归入口、依赖锁文件和兼容桥；生成的 `includes/vendor/` 继续按仓库规则排除，部署时按锁文件安装。本次源码更新不会自动打包或部署，测试脚本不应上传到生产站点。
